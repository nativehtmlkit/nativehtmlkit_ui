# Tutorials

Step-by-step lessons that build one real application, the same expense tracker in both
languages. Each step is a complete program in [`code/`](code/), verified with the example
harness against the real NativeHTMLKit host.

| Tutorial | Builds | Finished app |
|---|---|---|
| [Python: build an expense tracker](python-expense-tracker.md) | Inputs, list, validation, filter, computed totals | [`examples/python/expenses.py`](../../examples/python/expenses.py) |
| [PowerShell: build an expense tracker](powershell-expense-tracker.md) | The same app with `NativeHTMLKit.UI` (PowerShell 7 and Windows PowerShell 5.1) | [`examples/powershell/expenses.ps1`](../../examples/powershell/expenses.ps1) |

Afterwards continue with the [how-to guides](../guides/README.md) or browse the
[examples](../../examples/README.md).
