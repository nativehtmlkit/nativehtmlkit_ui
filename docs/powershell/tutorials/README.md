# Tutorials

Step-by-step lessons for the PowerShell UI library 0.1.1. Each step is a complete program in the
repository's [`examples/tutorials/powershell`](https://github.com/nativehtmlkit/nativehtmlkit_ui/tree/main/examples/tutorials/powershell)
folder, and the finished app is a catalogue example; all of them are run by the example harness
against the real NativeHTMLKit host. The same tutorials exist for Python:
[Python tutorials](../../python/tutorials/README.md).

| Tutorial | You build | Finished app |
|---|---|---|
| [Build an expense tracker](expense-tracker.md) | Inputs, a list, validation, a filter and computed totals | [`expenses`](https://github.com/nativehtmlkit/nativehtmlkit_ui/blob/main/examples/powershell/expenses.ps1) |
| [Build a settings editor](settings-editor.md) | Load and save a JSON file, validation messages, unsaved-changes tracking, Revert | [`settings_editor`](https://github.com/nativehtmlkit/nativehtmlkit_ui/blob/main/examples/powershell/settings_editor.ps1) |

Start with [getting started](../getting-started.md) if you have not installed the library yet.
Afterwards continue with the [how-to guides](../guides/README.md) or browse the
[examples](../examples.md).
