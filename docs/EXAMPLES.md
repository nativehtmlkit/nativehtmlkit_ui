# Component demos

| Example | Purpose |
|---|---|
| `examples/python/counter.py` | State, computed values, buttons, input and list |
| `examples/python/background.py` | Background work reported with `ui.post()` |
| `examples/powershell/counter.ps1` | Equivalent PowerShell state, computed and declarative layout |
| Public `examples/python-ui/gallery.py` | Interactive Python UI gallery |
| Public `examples/powershell-ui/gallery.ps1` | Interactive PowerShell UI gallery |

The public galleries are teaching examples, not screen-reader certification or performance evidence. Their source must be reviewed and exercised on both target desktops before screenshots are published.
