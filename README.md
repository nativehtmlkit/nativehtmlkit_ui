# nativehtmlkit_ui

A small, responsive and reactive native desktop UI toolkit for **Python** and **PowerShell**, built on the public NativeHTMLKit SDKs. Separate repository, one shared visual system, two native-language implementations.

**Status: implementation candidate 0.1.0.** Python fake-SDK tests pass in the provided development environment. PowerShell and real interactive native GUI gates require local qualification; see `docs/QUALIFICATION.md` and `docs/VERIFICATION.md`. This is source ready for local-agent validation, **not a qualified release**.

## Architecture

```text
Python application                       PowerShell application
   |                                           |
nativehtmlkit_ui                          NativeHTMLKit.UI
   |                                           |
public nativehtmlkit Python SDK           public NativeHTMLKit PowerShell SDK
   \____________________    ___________________/
                        \  /
               NativeHTMLKit Core (only via SDKs)
```

There is **no** direct Core import, IPC handling, Rust source, Core binary, browser, HTTP server, JS, or cross-language dependency. The SDK supplies the host and remains responsible for process/window/document lifecycle.

## Use it in a NativeHTMLKit Project workspace

Unzip or clone this repository under `nativehtmlkit-project/repositories/nativehtmlkit_ui/` as a **separate Git repository** (not a Git submodule or subtree). Parent Project convention excludes child repositories from its own Git index. See [`docs/INTEGRATION.md`](docs/INTEGRATION.md).

## Install Python (local/offline)

```bash
# Install the qualified Python SDK wheel in the desired venv first.
cd python
python -m pip install --no-build-isolation --no-deps -e .
# For tests, no SDK host is required:
PYTHONPATH=src python -m pytest -q tests
```

```python
from nativehtmlkit_ui import UI, state

def main(app):  # `python -m nativehtmlkit run yourmodule:main --name MyApp`
    counter = state(0)
    ui = UI(title="Counter")
    with ui.column():
        ui.heading("Counter")
        ui.text(lambda: f"Value: {counter.value}")
        ui.button("+", on_click=lambda e: counter.set(counter.value + 1))
    ui.mount(app)
```

The host-first SDK runner owns readiness and `app.run()` for module entrypoints. See `examples/python/counter.py` for a direct script.

## Install PowerShell (local/offline)

Install the NativeHTMLKit SDK module, then copy `powershell/NativeHTMLKit.UI` into an appropriate path on `$env:PSModulePath` or import the module manifest directly. A packed module is generated by `python tools/package-local.py`.

```powershell
Import-Module NativeHTMLKit.UI
$app = Start-NativeHTMLKitScript -Name 'Counter'
$ui = New-NHKUi -Title 'Counter'
$count = New-NHKUiState -Value 0
$null = Add-NHKUiColumn -UI $ui -Content {
    $null = Add-NHKUiHeading -UI $ui -Text 'Counter'
    $null = Add-NHKUiText -UI $ui -Bind $count
    $null = Add-NHKUiButton -UI $ui -Text '+' -Data $count -OnClick {
        param($eventObject,$state) $state.Set([int]$state.Value + 1)
    }
}
try {
    $null = Start-NHKUi -UI $ui -Application $app
    Wait-NativeHTMLKit -Application $app -UntilShutdown
} finally {
    Stop-NHKUi -UI $ui
    Close-NativeHTMLKit -Application $app
}
```

`Start-NHKUi` creates a native window and marks the SDK app ready. The SDK's `Wait-NativeHTMLKit` remains the event pump. PowerShell state updates belong on the SDK owner runspace. Use SDK task completion callbacks for background results.

## Included (deliberately small)

- State and computed values; explicitly bound text and input state; limited conditional display and text-list regions.
- Buttons, text inputs, checkbox, select, alert, badge; row/column/grid/card/heading/text.
- CSS-based responsive layouts; Cobalt, Graphite and Daylight themes; compact, regular and comfortable density.
- Python owner-thread task posting; PowerShell SDK owner-runspace callbacks; delegated document events.
- Native DOM updates through **public** SDK methods only; bounded queue and error diagnostics.
- Scoped disposal, test doubles, simple examples, offline packaging and qualification documentation.

## Not included

No extension/plugin host, contribution registry, ViewSpec, virtual DOM, HTTP/JS, full router, persistence, form schema engine, rich table, chart library, virtualized lists or compiled PowerShell helper. The `text_list` control replaces one text-only region on change. `when` changes visibility; it does **not** construct/dispose subtrees dynamically.

## Limits and security

- `raw_html()` / `Add-NHKUiHtml` and custom CSS are for **trusted** application-provided source only. Never interpolate untrusted text into markup. Normal text controls escape HTML.
- Do not mix raw document mutations with managed bindings inside the same owned subtree without explicit coordination.
- Python `state()` accepts cross-thread changes and marshals DOM writes onto one UI owner. PowerShell `.Set()` must be invoked on the owning runspace after mount.
- Native events are post-dispatch; prevent default actions *before* the event using the underlying public SDK API.
- SDK queue pressure, input/IME correctness, native CSS rendering and host shutdown all require real qualification. Do not infer interactive readiness from pure-unit tests.
